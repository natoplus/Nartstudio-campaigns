# Nartstudio Campaigns

Campaign planning and launch resources for creative projects. The site provides educational content and a local checklist; it does not represent active campaigns or accept campaign payments.

## Pages

- `/` - overview
- `/campaigns` - campaign planning guidance
- `/playbook` - launch playbook
- `/planner` - local launch checklist

The planner saves its working title and checklist in browser storage on this device only. It does not submit data to a server. If storage is unavailable or the saved content is invalid, an accessible status message explains the issue and the checklist remains usable for the current visit. Studio enquiries open the visitor's email application.

```bash
npm install
npm run dev
```
